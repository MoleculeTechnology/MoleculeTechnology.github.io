## Motion capture clothing

The Unity SDK connects Enflux's Bluetooth motion capture clothing to applications built by business partners + consumer developers.

The application work spans **five first-party applications + four investor demos**, including a demo featured on TechCrunch.

## Blender motion capture plugin

The Blender plugin records motion capture animation + exports FBX files. A Unity-based Windows application sends smooth motion data over Wi-Fi to Blender on other computers.
