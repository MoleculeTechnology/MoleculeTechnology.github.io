## Core systems + platforms

I shipped **nine major Hearthstone expansions between March 2021 and August 2023**.

My responsibilities included core systems, memory and download performance, native mobile development, client build tooling, FX artist tools, and SDK integrations.

I debugged low-level game engine issues and supported engineers across other teams with guidance and solutions to blocking problems.

## Content pipeline + artist tools

I maintained and improved the asset pipeline used to pack + ship all the game's content worldwide for a long-running live-service game across desktop and mobile.

I also worked on the client build tooling and tools used by FX artists.

## Current work / Unannounced game

In my current role on an unannounced game, I work heavily on **3D graphics techniques, rendering, and content pipeline tools for art + audio**.
