## Core systems + platforms

Core systems engineering supported **nine major Hearthstone expansions between March 2021 and August 2023**.

Core systems work covered memory and download performance, native mobile development, client build tooling, and SDK integrations.

Low-level engine debugging and cross-team engineering support addressed blocking technical issues.

## Content pipeline + artist tools

The asset pipeline packs + ships the game's content worldwide across desktop and mobile. Engineering work included pipeline maintenance and improvements, client build tooling, and tools for FX artists.
