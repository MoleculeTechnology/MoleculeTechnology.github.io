Blizzard / Hearthstone

Behind the creative world

Core engine technology, content pipelines, and artist tools for Hearthstone at Blizzard.

Contribution
Core systems, asset pipelines, artist tools, performance, and native mobile development
Context
A live-service game across desktop and mobile platforms

Engineering that supports creative work #

My work on Hearthstone at Blizzard covered the core technology that helps a creative game run, grow, and reach players across platforms. It brought together engine behavior, content delivery, performance constraints, and the tools used by other disciplines.

Content and artist tools #

I maintained and improved the asset pipeline used to pack and ship the game’s content worldwide. My responsibilities also included client build tooling and tools for FX artists.

I care about the connection between making creative content and getting that content into a working experience. The tools and pipeline affect what artists can make and how easily a team can iterate.

Core engine and platform work #

My responsibilities included memory and download performance, native mobile development, SDK integrations, and low-level engine issues. I also supported engineers on other teams with guidance and solutions to blocking problems.

Multi-platform development makes the constraints concrete: the same creative work needs to reach people using different devices and operating environments.

How it connects #

My current engineering focus includes 3D graphics techniques, rendering, and content pipeline tools for art and audio.

This experience supports the engineering side of my creative practice: understanding rendering and runtime constraints, building tools for other people, and carrying work through to delivery. Together with film-set experience and motion capture tools, it informs the way I approach interactive work as Molecule.
