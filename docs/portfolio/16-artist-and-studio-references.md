# Artist and studio portfolio references

Russell rejected the rework's generic promotional language and prefers the original About page's writing and pictures.
This study looks at how established digital and installation practices document actual work.
The applications to Molecule below are editorial recommendations, rather than claims about the artists' intentions or Russell's influences.
Sources are official portfolio pages reviewed on 2026-10-24. Some referenced pages are historical project archives.

Read alongside the [copy and media revision plan](17-copy-and-media-revision-plan.md).

## The closest references for this particular portfolio

### Rhizomatiks: artistic and engineering work deserve explicit credit

The `discrete figures` archive provides an especially relevant structure: the work has its own presentation, while technology and credits have dedicated pages.
The technology text describes specific operations, including motion analysis and tracking hardware.
The credits name software and hardware engineering as distinct contributions alongside choreography, music, and artistic direction.
Sources: [technology](https://research.rhizomatiks.com/s/works/discrete_figures/en/technology.html), [credits](https://research.rhizomatiks.com/s/works/discrete_figures/en/credit.html).

For Molecule: a short introduction should lead to a convincing visual record. A second layer can explain rendering, playback, tracking, tooling, or firmware, with Russell's role stated directly.
This is especially useful for Paper Ghost, Enflux, and independent hardware work.

### NONOTAK and Jim Campbell: concise project records

NONOTAK's DAYDREAM V.6 page puts a small amount of factual text beside many images.
Campbell's Exploded Views page adds dimensions, materials, commissioning information, and a short account of the work.
Sources: [DAYDREAM V.6](https://www.nonotak.com/_DAYDREAM-V-6), [Exploded Views](https://www.jimcampbell.tv/portfolio/exploded-views).

For Molecule: try actual project names, a medium or deliverable, and a contribution line in the homepage grid. Move detail to the project page.
This would make the original About page's project material more visible without requiring an advertising headline for every item.

### Lozano-Hemmer and RANDOM INTERNATIONAL: describe the interaction

Pulse Room explains the participant's action and the sequence of visible responses. Rain Room describes the visitor's relationship to the falling water.
Sources: [Pulse Room](https://www.lozano-hemmer.com/pulse_room.php), [Rain Room](https://www.random-international.com/rain-room).

For Molecule: the eventual Moongoat description should name what was shown, what a visitor could do, and what actually happened in response.
The event photo alone cannot supply that account.

## What to avoid borrowing

Several of these sites also use sweeping language about perception, boundaries, transformation, or immersion.
Russell has specifically rejected comparable language in this rework.
Use the useful documentation structures and the concrete project details. Write Molecule's text from Russell's own work and words.

Artistic interpretation still belongs in the portfolio when it expresses an idea Russell actually holds.
The next pass should recover that voice from his descriptions and existing writing instead of supplying a generic artist statement.

No reference-site images, copy blocks, or visual identities were imported into the repository.
