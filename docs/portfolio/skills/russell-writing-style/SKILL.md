# Russell's writing style

- Do not use semicolons in original prose.
- Rewrite with periods, commas, conjunctions, or separate sentences as the meaning requires. Keep the phrasing natural.
- Preserve punctuation required by code, commands, structured data, HTML entities, URLs, and identifiers.
- Preserve exact quotations. Use a paraphrase when exact wording is unnecessary and would conflict with this preference.
- Check the finished prose for semicolons before handing it back.
