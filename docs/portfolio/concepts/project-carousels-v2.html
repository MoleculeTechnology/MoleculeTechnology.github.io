Molecule / Concepts for review

{ PROJECT CAROUSELS }

Choose a project to compare the same images with three different controls. These are planning versions, separate from the website.

A / Caption rail Recommended starting point

A caption, count, and arrows sit below the image.

The controls stay clear of the image. This can be the common pattern for every project without adding another row of pictures.

B / Corner controls

A small control panel sits inside the image frame.

Uses less space below the frame. It covers a corner of the photograph, which may be a problem for software interfaces or detailed set photos.

C / Small contact strip

Still thumbnails show which other views are available.

Makes the other images easier to discover. The added row is busier when repeated under several films. Thumbnails stay still, including those for looping images.

Images change only when selected. Looping images keep looping once selected. Titles, project links, and image frames stay in place. Try Tab, the arrow keys, Home, and End while a control has focus.
