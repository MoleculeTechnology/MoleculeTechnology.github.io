# Portfolio source media

Preserved originals for the portfolio. Keep original filenames and file bytes when copying media here. Prepared website assets live under `assets/portfolio/`.

## Molecule

- [Patch computer](molecule/patch-computer/) — original MP4 and GIF.
- [Lightsaber prototypes](molecule/lightsaber-prototypes/) — both original photographs.
- [PixelPerf Market, 2023-09-02](molecule/pixelperf-market/2023-09-02/) — five original photographs and the original GIF.

These ten files total 98,003,186 bytes. All copies match the original SHA-256 hashes in the [media manifest](../docs/portfolio/assets/molecule-selected-media.json). Its `repository_source` field identifies each preserved copy, alongside the VADER path and prepared website output.

See [Molecule selected photos and motion](../docs/portfolio/31-molecule-selected-media.md) for selection and preparation details.

The two original GIFs are served as smaller animated WebP images that loop continuously. See [Looping portfolio images](../docs/portfolio/32-looping-portfolio-images.md). Keep these GIF source copies unchanged when preparing new delivery formats.

This directory sits outside Hugo's content, asset, and static mounts. The website uses the prepared delivery files.
